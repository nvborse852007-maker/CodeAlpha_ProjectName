CodeAlpha Hangman Game

Project Overview

This project is a simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

The player guesses a hidden word one letter at a time. The game ends when the player guesses the word correctly or uses all 6 incorrect guesses.

Features

- Uses 5 predefined words.
- Randomly selects a secret word.
- Allows one-letter guesses.
- Limits incorrect guesses to 6.
- Displays the guessed word and remaining attempts.
- Runs in the console.

Technologies Used

- Python
- random module
- while loop
- if-else statements
- strings and lists

How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run this command:

python hangman.py
